Métodos de Manipulação de Arrays

Array Original: [5, 3, 8, 1, 4]

Array.sort()

Descrição: Ordena os elementos do array de forma crescente.

Resultado: [1, 3, 4, 5, 8]

const array = [5, 3, 8, 1, 4];
array.sort((a, b) => a - b);
console.log(array); // [1, 3, 4, 5, 8]

Array.reverse()

Descrição: Inverte a ordem dos elementos do array.

Resultado: [4, 1, 8, 3, 5]

const array = [5, 3, 8, 1, 4];
array.reverse();
console.log(array); // [4, 1, 8, 3, 5]

Array.toSorted()

Descrição: Retorna um novo array ordenado sem modificar o original.

Resultado: [1, 3, 4, 5, 8]

const array = [5, 3, 8, 1, 4];
const sortedArray = array.toSorted((a, b) => a - b);
console.log(sortedArray); // [1, 3, 4, 5, 8]

Array.toReversed()

Descrição: Retorna um novo array com a ordem invertida sem modificar o original.

Resultado: [4, 1, 8, 3, 5]

const array = [5, 3, 8, 1, 4];
const reversedArray = array.toReversed();
console.log(reversedArray); // [4, 1, 8, 3, 5]

Math.min()

Descrição: Retorna o menor valor do array.

Resultado: 1

const array = [5, 3, 8, 1, 4];
const minValue = Math.min(...array);
console.log(minValue); // 1

Math.max()

Descrição: Retorna o maior valor do array.

Resultado: 8

const array = [5, 3, 8, 1, 4];
const maxValue = Math.max(...array);
console.log(maxValue); // 8
